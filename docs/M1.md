Chrome checks at 1280px and 390px used the checked-in synthetic Lichess board against local FastAPI with the Lichess theme selected. With a test browser session, “Review next square” cycled through flagged squares and confirming squares reduced the count from three to zero. Sandbox FEN started collapsed, could be opened and closed, and stayed open when invalid FEN was corrected. The real browser Stockfish worker rendered numbered SAN, including `1. e4 e5 2. d4 exd4`. Neither page overflowed horizontally in these checks.
