# Product design review — November 2026

Reviewed all seven PNGs in this directory against the current `client-ui` components. These are follow-up findings; the earlier CRITIQUE.md and screenshots remain historical evidence, not captures of this change.

| Impact rank | Concrete fix and evidence | Status |
| --- | --- | --- |
| 1 | **Guide uncertain-square review.** Lens asks users to find five dashed squares themselves. Add a remaining count, a “Review next square” action, and clear confirmation; retain manual selection and allow search without forced confirmation. | Implemented |
| 2 | **Make correction controls comfortable to use.** Review selects, disclosure rows, and Search are smaller than the app’s 44px button standard. Apply 44px targets, clearer select borders, explicit accent-button text contrast, and a visible board focus outline. Board squares retain their responsive dimensions. | Implemented |
| 3 | **Make engine output readable chess.** Sandbox displays coordinate strings such as e1c1 and a crowded heading. Convert the continuation to numbered SAN, use a full-row title with a CPU icon, explain local execution, and label the depth slider. | Implemented |
| 4 | **Close the Sandbox spacing gap.** The desktop board caps at 576px while its grid column keeps growing, leaving a large gap before analysis. Cap that column at the board width, align the similar-position panel, and reduce the oversized evaluation bar from 256px to 160px. | Implemented |
| 5 | **Put position codes behind disclosure.** The long FEN string competes with the board and primary action. Collapse the Lens code and Sandbox FEN editor by default; keep invalid Sandbox input visible with its validation message. | Implemented |
| 6 | **Use one recognition animation.** OriginLens combines a scanning line and spinner. Keep the scan and status text; reserve skeletons for search. Preserve existing reduced-motion support. | Recommended |
| 7 | **Increase small supporting type.** Landing preview captions use .67rem and kickers .68rem. Raise these to at least 12px and reduce letter spacing so they remain readable on phones. | Recommended |
| 8 | **Make the landing CTA specific.** “Start studying” does not explain the next step (registration). Use “Create a free account” only if the service is confirmed free; otherwise “Create an account,” with screenshot-to-replay context nearby. | Recommended |
| 9 | **Give match rows a stronger reading order.** Long player names compete with Replay on mobile. Put players first, metadata below, and give Replay its own consistent action area at narrow widths. | Recommended |
| 10 | **Reduce the idle results panel.** Before upload, Matching games repeats the instruction in a large empty card. Use a compact explanation of what will appear, expanding when searching or showing matches. | Recommended |

Validation: production build; focused lint of changed components; engine notation checks for both sides to move, castling, promotion, and malformed output.
