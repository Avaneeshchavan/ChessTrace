# Custom piece set — "stamp" series

Minimalist woodcut/rubber-stamp silhouettes, not the default Cburnett set
chessground ships with. Twelve SVGs (6 roles x 2 colors):

- White pieces: paper-fill body with a heavy ink outline (reads as
  "stamped in relief" against the ledger-paper background).
- Black pieces: solid ink silhouette, no outline (reads as "inked").

Shared visual grammar so the set reads as one family, faceted/angular
throughout (no soft curves, consistent with the ledger/woodcut aesthetic):

- King:   silhouette + a small cross-tipped spike
- Queen:  silhouette + five triangular points
- Rook:   silhouette with three square merlons
- Bishop: silhouette + diagonal mitre-slit
- Knight: angular horse-head silhouette
- Pawn:   dome-and-base silhouette, the family's base unit

Referenced by Board.css via `background-image: url(...)`, overriding the
chessground.cburnett.css piece rules imported in index.css.
